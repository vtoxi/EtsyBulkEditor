# Privacy Policy — Etsy Bulk Editor

**Last updated:** September 7, 2026

## Summary

Etsy Bulk Editor is a free Chrome extension that adds bulk-select tools to your Etsy shop manager. It does not collect, store, or transmit your listing data to any server. All operations are local.

## Data accessed

When you visit your Etsy shop manager listings page, the extension reads the publicly visible listing information already shown on the page (title, price, tags). This data is only used within your browser session to power the bulk toolbar. It is never sent anywhere.

## Data stored

The extension stores no data in chrome.storage. It generates CSV downloads saved to your device on request.

## Downloads

When you click Export CSV, the extension saves a CSV file to your Downloads folder containing the listing data you selected.

## Permissions

| Permission | Purpose |
|------------|---------|
| `storage` | Reserved for future settings (currently unused) |
| `downloads` | Saves exported CSV files to your Downloads folder |
| Host access to `etsy.com` | Required to inject the bulk toolbar into your Etsy shop manager page |

## Data we do not collect

This extension does not: require login, send data to any server, collect analytics, or track anything.
