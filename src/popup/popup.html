Etsy Bulk Editor
Shop Manager Tools
How to use
  1. Go to your Etsy shop manager → Listings
  2. The bulk toolbar appears automatically at the top
  3. Check listings you want to select
  4. Use the toolbar to bulk-copy tags, adjust prices, or export CSV
Features
☑️
Bulk select
Checkboxes on every listing. Select all or pick individually.
🏷️
Copy tags
Copy tags from one listing to clipboard for pasting in others.
💲
Price adjustment
Preview price changes by percentage across selected listings.
📊
Export CSV
Download selected listings as a CSV with title, price, and tags.
